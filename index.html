Java Implementation (App.java)

public class App {
  public static void main(String[] args) {
    HttpServer server = HttpServer.create(
      new InetSocketAddress(8080), 0
    );
    server.createContext("/api/greeting", 
      (exchange) -> {
        String res = "{\"message\":\"Hello, World!\"}";
        exchange.sendResponseHeaders(200, res.length());
        exchange.getResponseBody().write(res.getBytes());
      }
    );
    server.start();
  }
}

Deployment Instructions

Easily deploy this project to your preferred platform.

▲ Vercel (Front-end)

Go to vercel.com/new, import saschool12/java, and click Deploy. Vercel serves the web UI at your custom .vercel.app URL.

🚂 Railway (Full-stack Java)

Create a new project on Railway from saschool12/java. Railway automatically detects Gradle and executes ./gradlew run on port 8080.

🖥️ Local Development

Run ./gradlew run in your terminal. Open http://localhost:8080 in any web browser to see the live app.
